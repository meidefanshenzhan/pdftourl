# KJAMZ Word Counter 与跨境词频统计设计

日期：2026-10-25
状态：用户已批准；实现已完成本地验收，生产发布以验收记录为准。

## 目标与范围
在现有 KJAMZ 中英文工作台中新增 /zh/word-counter/ 和 /en/word-counter/，以 wordcounter.ai 的简洁编辑器、实时统计、可读性和目标字数功能为主要参考，补充 AMZ123 的卖家词频筛选。功能用于商品文案、关键词列表与普通文本分析，不以竞争 word counter 大词排名为上线前提。

不复制第三方品牌、源代码、FAQ 原文、营销承诺或有争议的平台字符限制。视觉使用 KJAMZ 暖白、深绿、浅绿、统一导航与联系入口。

## 实现方式与取舍
采用纯前端、浏览器本地分析，复用当前静态页面构建和 Cloudflare Worker 资源服务。没有登录、上传次数限制、AI 推理调用或新数据库表。服务端计算增加隐私和成本，嵌入第三方页面无法满足全量词频与统一 UI，因此不采用。

## 页面与交互
- 简短标题和用途说明；大文本编辑区在左、紧凑实时统计卡在右；移动端按编辑区、统计、词频顺序堆叠。
- 编辑区支持输入/粘贴、示例、复制、清空。默认空白，示例由用户点击加载，不混入真实输入。
- 字数、字符数（含/不含空白）、UTF-8 字节数、句子、段落、行数、唯一词数。
- 阅读时间按英文 200 词/分钟、演讲按 130 词/分钟估算。非英文文本明确提示只是估算，不伪装为语言通用标准。
- 英文可读性折叠卡：Flesch Reading Ease、Flesch-Kincaid Grade、ARI；音节为启发式估计，非英文占比明显时不输出误导性的英文分数；没有足够英文或空内容显示不可用。
- 可选目标字数：250/500/1000/2500/5000 与自定义正整数；显示实际数、百分比、完成状态，进度条最高 100%，文字百分比允许超过 100%。
- 不添加含糊的 AI 检测、语法纠错、翻译、搜索量或“最佳关键词密度”承诺。

## 词频与筛选
- 默认显示全部有效单词；不把底层结果截成前 10。数据多时分页，每页 100 项，保留全部结果和总项数。
- 可选全部、前 10/25/50/100 和自定义前 N；N 为正整数，超过总数时显示全部。
- 支持 1 词、2 词、3 词连续短语。短语不跨句子、段落或换行，以免把多条 Listing 或关键词列表拼成假短语。
- 默认不区分大小写；切换后分开计数。保留原始文本，不因筛选改动编辑内容。
- 默认排除英文常用虚词（如 the/and）；可关闭，可输入自定义排除词。中文不强行套英文停用词。
- 支持关键词搜索及最少出现次数；高级筛选折叠放置，主界面保持简洁。
- 按出现次数降序，相同次数按稳定的规范文本排序。默认不做词干合并，shoe 和 shoes 分别统计。
- 密度使用原始完整分词后的有效 1/2/3-gram 位置数作为分母，排除词、最少次数、搜索、前 N 不改变分母。表头/帮助明确当前分母口径，避免过滤后密度被人为抬高。
- 2/3-gram 的排除词过滤作用于完整短语，不先删除词再跨词拼接；可排除完全由停用词构成的短语，自定义排除按当前项精确匹配。

## 分词口径（实现判断，用户可纠正）
- Unicode 字母和数字作为词基础，英文内部撇号和连字符保留，标点不计作词；数字计词。
- 中文等无空格语言采用浏览器 Intl.Segmenter；缺失时采用可说明的 Unicode 降级处理。界面与 FAQ 说明不同软件统计口径可能不同，不承诺逐项等同 Word。
- 字符统计使用 Unicode 码点；UTF-8 字节单独用 TextEncoder 计算，避免把字符数与后台字节限制混用。
- 句子使用中英文终止标点与换行边界，空文本为 0；段落按非空文本块、空行分隔，并明确口径。

## CSV / TXT 导出
- 两个按钮直接导出当前筛选结果；旁边明确“导出当前筛选，共 X 项”，分页不截断导出。
- 默认全部，即默认导出全量。选前 N 后导出相应 N 项；搜索、词长和排除设置同样反映在导出中。
- 列为排名、关键词/短语、出现次数、密度百分比；TXT 以制表符分隔并写明统计设置/分母。
- CSV 为 UTF-8 BOM、CRLF、规范引号转义，方便中文 Excel；防止以 =、+、-、@ 等开头的单元格被表格软件当成公式。
- 文件名有工具与时间，不含输入内容。空结果导出按钮禁用。下载发生在本地，不向后台发送文本。

## 隐私、性能与异常
- 默认不持久保存用户文本；提供“仅在此浏览器保存草稿”可选开关，明确共享电脑注意事项。关闭或清空时只删除本工具命名空间，不清整个站点 localStorage，不影响 PDF 访客记录。
- 语言切换保留同一会话输入和筛选；同源本地草稿不随 URL 查询参数、外链或日志传输。
- 统计计算在 Web Worker 中，输入防抖约 150ms，序列号防止旧结果覆盖新输入；渲染分页防止全量 DOM 卡顿。
- 初版明确最多处理 500,000 字符；超限不静默截断，提示用户缩小输入后分析，保留编辑区内容且禁止导出旧结果。
- 处理 Intl.Segmenter、Worker、localStorage、Clipboard 不可用等情况；复制失败提示手动复制，草稿保存失败不阻止统计。
- 输出使用 textContent，不将用户输入注入 HTML；无任意 URL 抓取，无外部脚本和文本分析 API。

## 内容与导航
- 主页新增“词频统计 / Word Counter”已上线工具卡，与 PDF 工具并列；两工具之间用正常链接互相发现。
- 原创中英文使用说明与 FAQ：统计什么、怎样分词、大小写与停用词、密度计算、如何导出全部、隐私与草稿、中文字节与字符差异、与 Word 差异、是否保证搜索排名。
- 说明它分析用户提供文本内的重复，不提供搜索量、不推荐堆砌词频、不判断商品是否满足 Amazon 全部政策。
