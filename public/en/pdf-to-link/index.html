A few useful answers

Will these links expire?+

No scheduled expiry is applied. Availability depends on continued hosting, account status and the file not being deleted. Unconditional permanent storage is not promised.

Can I use this across Amazon marketplaces?+

The tool produces a standard PDF file URL for the relevant document field in your marketplaces. Check each marketplace, category and document type at submission.

Do I need to register or sign in?+

No. Create 3 links per hour in the same browser. An upload code is requested only after that limit; it unlocks uploads for 1 hour. Clearing browser data or switching browsers affects history and quota recognition.

Does it edit or translate my PDF?+

No. The file is checked before upload and its original bytes are preserved. Switching the website language does not translate documents.
