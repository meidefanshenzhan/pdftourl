Good to know

How are additions and deletions counted?+

A continuous run of added content counts as one added fragment; a continuous deletion counts as one deleted fragment. Replacements usually produce both. These counts are not word counts or edit-history counts.

Do ignore options change my originals?+

No. They affect matching, while each panel keeps its own text form. Line mode retains line boundaries when ignoring whitespace. Word mode ignores spaces, tabs and newline items.

What does the TXT report contain?+

The report includes the selected rules, both original versions, and added and deleted fragments. It is a readable record for reviews and handoffs.

Is my text sent to a server?+

Comparison, copying and report export run in your browser. Input text is not sent to the server and drafts are not saved automatically. Save what you need before refreshing or closing the page.
