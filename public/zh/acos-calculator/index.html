GOOD TO KNOW

使用前你可能想知道

ACOS 和 ROAS 有什么关系？+

ACOS 是广告花费除以广告归因销售额，通常用百分比表示；ROAS 则为广告归因销售额除以广告花费。例如 ACOS 20% 对应 ROAS 5。

平台佣金可以按金额填吗？+

可以。选择按售价百分比或固定金额，使用与你商品实际费用一致的数值；其他费用按每件商品分摊。

CVR 为 0、CPC 为 0 时怎样计算？+

CVR 为 0 时没有可估算的成交订单，每单广告花费与利润显示“—”。CPC 为 0 且 CVR 大于 0 时，每单广告花费按 0 估算，ROAS 因花费分母为 0 而显示“—”。

目标每单利润如何影响出价空间？+

目标利润越高，可留给广告的预算越少。目标利润恰好等于广告前贡献利润时，CPC 上限为 0；超过时会提示当前条件下无法达到。

输入的数据会保存吗？+

测算在当前浏览器进行，不上传或自动保存输入。可复制结果或下载 CSV / TXT，以便留存测算条件和结果。
