# PDF转URL临时文件分享网站

## 项目简介
本网站用于将本地PDF或其他文件上传到云端，自动生成可公开访问的URL链接，方便在亚马逊等平台后台"合规媒体位置来源"字段中填写。网站极简、苹果风格，支持多语言，适合所有用户，尤其是非技术用户。

## 主要功能
- 支持多文件上传（不限于PDF，任意文件类型）
- 上传后自动生成公网可访问的URL链接
- 支持上传历史记录，方便管理和复制链接
- 支持删除历史记录（如API支持则可云端删除，否则本地移除）
- 文件自动在7天后失效，无需手动清理
- 极简苹果风格界面，操作简单
- 支持多语言切换（默认英文，支持中文等）
- 纯前端实现，部署在Vercel，安全高效

## 使用方式
1. 打开网页，选择或拖拽文件上传（可多选）
2. 等待上传完成，页面会显示每个文件的URL链接
3. 可一键复制链接，粘贴到亚马逊等平台后台
4. 上传历史会自动保存，方便后续管理
5. 可删除历史记录（如API支持则云端删除，否则本地移除）
6. 文件7天后自动失效，历史会自动刷新

## 技术方案
- 前端：HTML5 + CSS3 + JavaScript，极简苹果风格
- 文件托管：对接 [filebin.net](https://filebin.net/) 第三方临时文件托管服务，匿名上传，自动失效
- 历史记录：本地 localStorage 保存上传历史
- 多语言：内置多语言包，支持切换
- 部署：Vercel 静态托管

## 局限说明
- 文件仅在 filebin.net 保留7天，之后自动删除，URL失效
- filebin.net 为第三方服务，偶尔可能因容量满而无法上传
- 上传内容请勿包含隐私、敏感或违法信息，所有人持有链接即可访问
- 删除功能依赖API支持，部分情况下仅能本地移除历史
- 文件大小不限制，但受 filebin.net 服务本身约束
